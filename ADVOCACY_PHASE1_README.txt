MAKUENI YOUTH NETWORK — ADVOCACY PLATFORM PHASE 1

Implemented in this phase:
- Advocacy Campaigns
- Youth Opportunities Portal
- Resource Centre
- Media Centre
- Frequently Asked Questions
- Accessibility controls (text size, high contrast, readable font)
- Website-wide search for programmes, impact posts and new advocacy content
- Newsletter subscription and admin subscriber list
- Admin site analytics (page views and content/subscriber counts)

Explicitly NOT added in this phase:
- Get Involved expansion
- Social feed
- Live statistics
- Partner directory expansion
- Project portfolio
- Public impact dashboard
- Innovation showcase
- Events calendar expansion
- Volunteer portal expansion
- Interactive county map
- Youth voices / success stories

DATABASE
For an existing MYN database, import ONLY:
  database/advocacy_phase1_upgrade.sql

This creates the new tables without dropping or replacing existing data.

For a completely new installation, database/myn.sql also contains the new tables.
